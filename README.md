# Paradise Nursery

A responsive React plant shop application for Paradise Nursery.

## Features

- Landing page with the company name and a **Get started** button
- About section explaining the company
- Product listing with category filters and search
- Cart reducer functions: `addItem()`, `removeItem()`, and `updateQuantity()`
- Cart drawer with quantity controls, remove action, subtotal, and checkout feedback

## Run locally

```bash
npm install
npm run dev
```

## Required source files

- `src/components/AboutUs.jsx`
- `src/App.css`
- `src/App.jsx`
- `src/store/CartSlice.jsx`
- `src/components/ProductList.jsx`
- `src/components/CartItem.jsx`
